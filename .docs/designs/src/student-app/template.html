Rocha's Surf School · student app

Student app

One flow per tab: Agenda, As minhas, Escola and Perfil. Each screen in light and dark, in the order the student meets it.

Agenda
AGENDA-01Week
Light
Dark

Home tab. Week picker with dots for days that have classes; the day’s classes as cards. The bell opens AGENDA-07.

AGENDA-01AMonth
Light
Dark

Tapping the date caption expands the full month. Picking a day collapses back to that week.

AGENDA-01BSport filter
Light
Dark

Floating button, bottom right: Todas · Surf · Skate. Choosing “Todas” clears the filter.

AGENDA-02Class detail
Light
Dark

Time range, location, instructors, occupancy and confirmed students. With spots open, the CTA asks to join (AGENDA-03).

AGENDA-02AFull class
Light
Dark

No spots left. The CTA switches to the waiting list; if a spot opens, the request goes to the admin for approval.

AGENDA-03Request to join
Light
Dark

Confirmation sheet with the sport’s cancellation rule. The student must accept it before sending; the request then shows as pending.

AGENDA-04Past class
Light
Dark

Once a class ends, the detail gains “Depois da aula”: rating (AGENDA-05) and class photos (AGENDA-06).

AGENDA-05Rate class
Light
Dark

Stars and an optional comment, alongside the rest of the class’s reviews. The student can edit or delete their own.

AGENDA-06Class photos
Light
Dark

Shared gallery. Only students who took part can add photos; everyone else can view.

AGENDA-07Notices
Light
Dark

Opened from the bell. Request updates, cancelled classes and school messages; “mark all as read” clears the badge.

As minhas
MINHAS-01My classes
Light
Dark

Every request the student made, with its status. The clock icon opens the history (MINHAS-05).

MINHAS-01AFiltered
Light
Dark

Status chips narrow the list — here, pending and waiting-list requests.

MINHAS-02Enrolled
Light
Dark

Approved request. The status banner confirms the spot; the CTA becomes “Cancelar inscrição”.

MINHAS-03Cancel enrolment
Light
Dark

Confirmation with the deadline for cancelling without penalty. Pending requests use the same sheet to withdraw.

MINHAS-04Rejected · reason
Light
Dark

Tapping a rejected banner shows the admin’s note. The student can request again.

MINHAS-05History
Light
Dark

Classes already taken, with a calendar to jump to a date. Each entry opens the past-class detail.

Escola
ESCOLA-01People
Light
Dark

Everyone at the school. Search by name and filter by role: students, instructors, admins.

ESCOLA-02Person
Light
Dark

Profile card. WhatsApp only appears if that person made their number visible.

Perfil
PERFIL-01Profile
Light
Dark

Photo (tap to change), WhatsApp, theme, language, rules, about, sign out and account removal.

PERFIL-02WhatsApp
Light
Dark

Edit the number and choose whether other students can see it. Instructors and admins always can.

PERFIL-03Theme
Light
Dark

Same as the phone (default), light or dark.

PERFIL-04Language
Light
Dark

Português, Español or English — the same choice offered at sign-in.

PERFIL-05School rules
Light
Dark

Read-only copy of the rules accepted at sign-up.

PERFIL-06Cancellation rules
Light
Dark

How many hours before each sport’s class you can cancel without penalty.

PERFIL-07About
Light
Dark

App version, school contacts and legal links.

PERFIL-08Sign out
Light
Dark

Confirmation before signing out; returns to LOGIN-01.

PERFIL-09Remove account
Light
Dark

Destructive confirmation. Signing in later shows LOGIN-10, where the student can ask for reactivation.
