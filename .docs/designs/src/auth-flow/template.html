Alternative states
Proposal · simplified while planning spec 014
  • One shared layout for every closed account: icon tile → eyebrow → title → description with the email → optional note card → optional primary button → “Usar outro email”, always in the same place.
  • LOGIN-10 is one screen with three states, picked by the account’s reactivation status: not requested (was LOGIN-10), requested (was LOGIN-10A), denied (was LOGIN-10B). Requesting switches the state in place.
  • One secondary action: every state signs out and returns to sign-in, labelled “Usar outro email” (LOGIN-09 said “Terminar sessão”).
  • One contact button: “Falar com a escola” is the screen’s primary button with the WhatsApp glyph on both LOGIN-09 and LOGIN-11 (LOGIN-11 used an off-token WhatsApp green). It is hidden while the school has no WhatsApp number.
  • The denial note is optional: without a reason, LOGIN-09 shows no “Mensagem da equipe” card.
  • Copy in pt-BR, and no promise of an email answer: pushes are the only channel and don’t exist yet, so the screens say to sign in again to see the answer.
