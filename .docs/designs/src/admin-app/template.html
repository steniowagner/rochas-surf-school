Rocha's Surf School · admin app

Admin app

One flow per tab: Painel, Aulas and Perfil. Each screen in light and dark, in the order the admin meets it.

Painel
PAINEL-01Dashboard
Light
Dark

Home tab. Today’s classes by sport, weekly occupancy vs. last week, average rating, then the tools and school sections. The bell opens PAINEL-02.

PAINEL-02Notifications
Light
Dark

New requests, cancellations and reviews, newest first. Each item links to the screen where it is handled.

PAINEL-03Join the school
Light
Dark

New accounts waiting for approval, with recent decisions below. The person gets a push notification either way.

PAINEL-03AReject request
Light
Dark

Rejecting asks for an optional note, shown to the person on LOGIN-09.

PAINEL-04Reactivate accounts
Light
Dark

Requests from deleted accounts asking to come back, with their email and past classes.

PAINEL-05Class requests
Light
Dark

Requests grouped by class with each class’s occupancy. Full classes list the waiting order.

PAINEL-06Enrol a student
Light
Dark

Add a school student or a trial student (name + WhatsApp) to a class directly, skipping the request.

PAINEL-07Send notice
Light
Dark

Title and message to everyone, students or instructors. The recipient count updates live.

PAINEL-07AConfirm notice
Light
Dark

Final check naming who will receive it before sending.

PAINEL-08Cancellation rules
Light
Dark

One rule for surf, one for skate. The app reads it with each class’s data to work out the cancellation deadline.

PAINEL-09School settings
Light
Dark

Waiting list on/off and the school’s WhatsApp number shown to students.

PAINEL-10My classes
Light
Dark

Classes where the admin is also the instructor, week by week.

PAINEL-11School rules
Light
Dark

Rules every student accepts during onboarding. Add, edit, reorder or delete.

PAINEL-12People
Light
Dark

Students, instructors and admins with search and role filter.

PAINEL-12APerson
Light
Dark

Profile sheet with role actions: promote, demote or remove from the platform.

PAINEL-13Class ratings
Light
Dark

Average rating for today, week, month or all time, with the lowest-rated classes first.

PAINEL-14Weekly occupancy
Light
Dark

Seats taken and free per class across the week.

Aulas
AULAS-01Week
Light
Dark

Classes tab. Browse past and future weeks; cards flag “A decorrer”, “Finalizada” and “Sem instrutor”.

AULAS-02Class detail
Light
Dark

Instructors, enrolled students, pending requests and rules. Pencil opens the editor (AULAS-03).

AULAS-02AIn progress
Light
Dark

A class that has started: only instructors can still be changed.

AULAS-02BFinished
Light
Dark

After the class: photos and students’ ratings. No longer editable.

AULAS-02CCancelled
Light
Dark

Cancelled class, kept for the record. Not editable.

AULAS-03Edit class
Light
Dark

Sport, level, date, start and end, location, instructors and capacity. Saving notifies enrolled students and instructors.

AULAS-03ANew class
Light
Dark

Batch creation: several days and time slots at once, times suggested from the previous week.

AULAS-04Cancel class
Light
Dark

Destructive confirmation naming everyone who will be notified, with an optional message.

Perfil
PERFIL-01Profile
Light
Dark

Photo, WhatsApp, theme, language, school rules and sign out.

PERFIL-02WhatsApp
Light
Dark

Edit the admin’s number and its visibility to students.

PERFIL-03School rules
Light
Dark

Read-only view of the rules as students see them.

PERFIL-04Theme
Light
Dark

Same as the phone (default), light or dark.

PERFIL-05Language
Light
Dark

Português, Español or English.

PERFIL-06Sign out
Light
Dark

Confirmation before signing out; returns to LOGIN-01.
