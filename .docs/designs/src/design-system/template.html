08 — Regras

Como as telas devem ser desenhadas.

DS-08-01

Regras de uso

As regras de como as telas devem ser desenhadas.

  1. Uma ação primária por tela: só um botão sol.
  2. Uva só para destaque e seleção.
  3. Números em Barlow Condensed 700.
  4. Alvos de toque de pelo menos 44.
  5. Botões respondem ao toque com opacidade.
  6. Ações do cabeçalho são só o ícone (HeaderButton), sem círculo nem fundo.
  7. Nunca use cor, fonte ou raio fixos: use os tokens, para valer nos dois temas.
