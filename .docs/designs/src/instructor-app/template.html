Instructor app

One flow per tab: Painel, Aulas and Perfil. Each screen in light and dark, in the order the instructor meets it.

PAINEL-01Dashboard
Light
Dark

Home tab. The instructor’s classes today, weekly occupancy and average rating, then shortcuts. The bell opens PAINEL-02.

PAINEL-02Notifications
Light
Dark

Reminders, join requests, location changes, assignments, cancellations and student feedback. Each item opens its class.

PAINEL-03My classes
Light
Dark

Every class assigned to the instructor, upcoming first. The clock icon opens past classes (PAINEL-04).

PAINEL-04Past classes
Light
Dark

Classes already given, by month, with photo and rating counts.

PAINEL-05School rules
Light
Dark

Read-only rules students accept at sign-up.

PAINEL-06People
Light
Dark

Everyone at the school with search and role filter.

PAINEL-06APerson
Light
Dark

Profile card. WhatsApp shows only if that person shares it.

PAINEL-07Class ratings
Light
Dark

Average rating for today, week, month or all time, lowest-rated classes first.

PAINEL-08Weekly occupancy
Light
Dark

Seats taken and free per class across the week.

Dark

Light

AULAS-03BClass note

Private note on how the group went, for the instructors’ next session.
